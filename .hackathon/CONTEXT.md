# Event context

## Event
- **Hacktoberfest Hack Day Lviv** (PolyTech Code Fest 2026 × SKELAR, MLH). Lviv Polytechnic. Teams of 2–4; the challenge is revealed at the opening.
- **Prizes to target with one project:** the organizer challenge · Best Open-Source AI Project (public repo + licence). The team switched the product AI to OpenAI on 31.10, so Best Use of Gemma 4 is no longer targeted. Open-Source AI asks for open-source or open-weight AI: closed OpenAI models may not qualify (OpenAI's open-weight gpt-oss models would).
- **Best Open-Source AI Project (MLH × DigitalOcean, Hacktoberfest 2026):** "Build with open-source or open-weight AI: agent skills, model harnesses, applications, or anything in between. Publish it on GitHub with an open-source license." Enter separately at mlh.link/hf26-digitalocean. DigitalOcean in the stack is suggested ("consider"), not required: AI tools (mlh.link/digitalocean-starterkit-h26), libraries (mlh.link/digitalocean-libraries-h26), one-click Hermes deploy (mlh.link/digitalocean-hermes-h26). Cheap fit for us: Gemma 4 is open-weight, repo is public MIT; deploy the demo on DigitalOcean App Platform → QR code on the slides.
- **Judges reward** one complete end-to-end path. They punish a mocked core feature and LLM wrappers the team can't explain.
- **MLH rules:** no project code before the event; disclose AI tools in README › AI usage and the submission.
